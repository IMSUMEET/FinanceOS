# Pull Request Checklist

- [ ] Quality gate passes (CI green)
- [ ] PR report comment reviewed
- [ ] Tests added for all changes
- [ ] Regression test for bug fixes
- [ ] No generated files in diff (`coverage/`, `quality-reports/`)
- [ ] No secrets
- [ ] Description explains **why**
- [ ] Screenshots if UI change (optional but helpful)

See `CONTRIBUTING.md` for setup instructions.
